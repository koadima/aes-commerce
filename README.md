# La Table de Silgat

Site vitrine du club de belote de la ville et de la commune de Comsylga.

Site statique en HTML/CSS/JS pur — aucune compilation nécessaire.

## Structure

- `index.html` — page unique du site (sections : accueil, qui sommes-nous, rejoindre, apprendre la belote, événements, contact)
- `assets/css/style.css` — styles
- `assets/js/main.js` — menu mobile, formulaire d'adhésion
- `assets/img/` — visuels (favicon)

## Aperçu local

Ouvrir `index.html` dans un navigateur, ou lancer un petit serveur local :

```bash
python3 -m http.server 8000
```

puis visiter `http://localhost:8000`.
